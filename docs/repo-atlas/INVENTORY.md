## Notable risk flags (from scan)

- `snapxapp-emerge` — debug keystore hardcoded in `build.gradle`.
- `iching_sglprompt_rmscratch3` — `.env.production` committed; verify no live secrets.
- `og_iching_v2_emergent` / `og_iching_v1_emergent` — Supabase anon keys in `app.json` (anon keys are public by design, but confirm RLS is enforced).
- Most "emergent"/"bolt" repos contain `.emergent`/`.bolt` automation dirs and auto-generated commits — expect low human-authored history.

## Proposed next phases

1. **Phase 2 — Decide.** You confirm the keep/merge/archive calls above (especially the 9 iching archives + 2 empty repos). Archiving on GitHub is reversible (hides, does not delete).
2. **Phase 3 — Standardize previews for keepers** via three reusable GitHub Actions templates:
   - `web-preview.yml` — build + deploy to Pages/Vercel, comment the live URL on each push.
   - `electron-build.yml` — build installer per-OS, upload as workflow artifact.
   - `expo-apk.yml` — build APK (EAS/Gradle), upload artifact + Appetize link for in-browser run.
3. **Phase 4 — Dashboard.** This atlas grows a status table with live links: build badge, latest artifact, preview URL per keeper.
